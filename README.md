# Number Outlier Finder

A simple web application built with **Vue.js** that identifies an "outlier" value in a given array of integers based on parity (even/odd).

## 🚀 Features

- **Logic:** Finds the single even number in a list of odd numbers, or the single odd number in a list of even numbers.

## 🛠️ Technologies

- **Framework:** Vue 3
- **Build Tool:** Vite
- **Styling:** CSS (Scoped)

## 📦 Installation & Setup

1. **Clone the repository:**

```bash
  git clone https://github.com/musialek007/outlier-finder.git
```

2. **Clone the repository:**

```bash
    npm install
```

3. **Run the application locally:**

```bash
    npm run dev
```
